# **App Name**: SchemeSevak

## Core Features:

- Scheme Discovery: Allow users to discover relevant government schemes based on their profile and eligibility criteria.
- Eligibility Check: Enable users to check their eligibility for various schemes by answering a questionnaire.
- Application Assistance: Provide users with assistance in filling out and submitting applications for schemes, including document upload.
- Recommendation Engine: AI tool which recommends the appropriate schemes for a given user, based on their completed profile. Considers maximum benefits.
- Status Tracking: Allow users to track the status of their applications in real-time.
- User Profile Management: Enable users to manage their profile information, including personal details, eligibility criteria, and documents.
- Admin Dashboard: Provide an admin dashboard for managing schemes, applications, and user accounts.

## Style Guidelines:

- Primary color: A deep teal (#2C5C77) to convey trust and stability, referencing the provided color.
- Background color: Light gray (#F5F5F5) to ensure a clean and professional look, as specified in the prompt.
- Accent color: Vibrant orange (#FF6B35) for calls to action, drawing attention and encouraging user interaction.
- Body and headline font: 'Inter' sans-serif for a modern and accessible user interface.
- Employ Material Design Icons from Google for a consistent and recognizable visual language. The set will be fully accessible, passing a color-blindness test.
- Implement a responsive, mobile-first layout to ensure accessibility across all devices.
- Use subtle transitions and animations to enhance user engagement and provide feedback on interactions.
